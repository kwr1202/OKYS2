# OKYS2
Bu proje, kütüphane işlemlerini (kitap, kopya, kullanıcı ve ödünç kayıtları) takip etmek için hazırlanmış basit bir Java uygulamasıdır.

## Proje Yapısı
- **src/**: Java kaynak kodları (`Kitap.java`, `KitapKopyasi.java`, `Kullanici.java`, `OduncKaydi.java`, `Main.java`)
- **doc/**: Sistem gereksinimleri belgesi
